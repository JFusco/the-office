# Overseer phase 6c launcher packaging for JFusco/the-office#647

Generate and commit one Node ES module in the operator checkout. The person-run installer already accepts that file as a buffer and publishes it at the stable launcher path. Install-time bundling would add a build tool to installation. Digest directories would add publication and retention work. Use reviewed plan `e0d61cef-c861-4346-b650-55436123023c` for the v1 contracts, pass behavior, recovery, counting and delivery criteria.

## Split the maintained source

- [ ] Extract `scripts/overseer-launch.mjs` into the following files under `scripts/overseer-launcher/`. Use static sibling ESM imports and actual `node:` built-ins. Export functions from the file that owns them.

| File | Responsibility |
|---|---|
| `launch.mjs` | Route `--group UUID` to `helperMain` or coordinate one launcher tick through lock, recovery, validation and dispatch. |
| `recover-attempt.mjs` | Resolve a saved `current` through `recoverCurrent`. |
| `dispatch-pass.mjs` | Supervise one new pass through `dispatch` and `stopOrWait`. |
| `configuration.mjs` | Validate the deadline and Office origin. |
| `runner-root.mjs` | Resolve safe runner paths through `protectedRoots`, `physicalPath`, `checkRunnerRoot` and `launcherPaths`. |
| `durable-files.mjs` | Perform checked I/O on owned files, including bounded reads and `publishDurable`. |
| `release-verification.mjs` | Establish the pinned launch inputs through pin, manifest, runtime revision, entry and local-loader checks. |
| `launcher-state.mjs` | Maintain the v1 launcher state, including validation, publication and history settlement. |
| `pass-outcome.mjs` | Classify a completed pass from its exit facts and final record. |
| `process-group.mjs` | Establish process-group ownership for observation and bounded cleanup. |
| `launcher-lock.mjs` | Serialize launcher ticks through `acquireLauncherLock`. |
| `helper.mjs` | Run the authorized candidate as the trusted group leader. |
| `field-checks.mjs` | Validate shared scalar and record fields. |
| `limits.mjs` | Define the fixed launcher bounds. |
