# GitHub delivery and recovery

The Office gives models implementation and review decisions. The harness owns candidate worktrees, GitHub and board mutations, merge readiness, and closeout. Durable Effects preserve mutation intent and reconcile uncertain outcomes through provider read-back.

The initial hands-off rollout introduced this division for Brain. Later changes extended retry and recovery without giving abandoned model runs authority to publish. The simplification in PR #212 and deterministic intake in PR #335 consolidated work around the ordinary delivery path. Approved prerequisites are evaluated as structured gates. A reviewed PR that starts to conflict after its readiness review stopped is refreshed by the harness on the next observation, under the same eligible-head rule, budget and exclusions as any conflict refresh, with the stopped verdict kept in the job's steps ([journal](../journal/2026-11-26-refresh-stopped-review-conflicts.md)). A stopped job those refresh rules refuse on local state alone costs that sweep no GitHub read ([journal](../journal/2026-11-26-stopped-sweep-local-eligibility.md)). A verified saved writer that declares prerequisites is adopted without a replay when its paid-run count is `0` or not reported (`null`); a reported positive count prevents adoption.

The Office can adopt eligible Context Wiki reconciliation PRs when a project opts in. It validates the bot account, commit history, and Markdown and graph-data scope. A canonical wiki PR title may carry exactly one trailing ` [skip release]` marker, for repositories whose release policy needs it; no other title variation qualifies ([journal](../journal/2026-11-25-wiki-sync-skip-release-titles.md)). Qualified wiki PRs proceed directly to required current-head GitHub checks and repository merge rules. A conflicted adopted bot PR (wiki-sync, Dependabot or Pin Courier) is redone by its own bot, once per conflicted head and never by an Office commit; its qualified replacement head merges on the ordinary path, and a numbered wiki PR whose regeneration left it unchanged is closed as superseded only on a proof that its target already contains it ([journal](../journal/2026-11-26-bot-pr-conflict-redo.md)).
