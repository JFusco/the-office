# Drawer navigation

Mixed-topic drawers now open on an overview. A user can pick a ticket from the mailbox, inspect its evidence, and use Back twice to return to the ticket row. Keeping the frame open preserves the view of the room and makes the return destination predictable.

The drawer fixture tests cover the path on desktop and phone, focus and scroll restoration, settings edits and conversation drafts. See [the implementation issue](https://github.com/JFusco/the-office/issues/551).
